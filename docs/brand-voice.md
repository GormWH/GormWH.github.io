# Brand voice

Applies when writing copy on the site (hero, about, project descriptions, blog, etc.).

## Voice

- **Personal copy:** `I` voice — calm and direct (no `we`).
- **Project descriptions:** neutral third-person.

## Typography rules

### English / UI chrome (site-wide)
- **No emoji.**
- Allowed glyphs: `→ · — ※ ✻`.
- Sentence case for headings.
- ALL CAPS only for tiny mono labels.

### Localized content (ja-jp / ko-kr)
- CJK text and native punctuation are allowed and expected (e.g., Japanese hiragana/kanji/katakana, Korean Hangul, Chinese punctuation marks like 「」or ・).
- The glyph allowlist above applies only to English UI chrome and site-wide elements; localized content follows standard CJK conventions.

## Languages in scope

EN / JP / KR. The live hero already mixes all three:

```
한국어 · 日本語 · English
```

English is the default. Japanese and Korean translations are added per-article (see [`docs/i18n.md`](i18n.md) for translation workflow).
